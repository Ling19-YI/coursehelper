## 更新内容

### 修复：AI 答题卡死

用户反馈答题时界面一直卡住不动，只能强杀进程。根因是视觉接口的 HTTP 请求**完全没有超时**——中转服务一旦不响应，请求就永久挂起；而答题期间卡顿检测被冻结，导致没有任何机制能把控制权交还给视频流程。

本次加了三层兜底：

1. **单请求超时 75 秒** — 到期主动中断并报「视觉接口超时」
2. **单轮答题总预算 240 秒** — 超时后不再发送新请求，用已获得的答案作答剩余题目
3. **视频层看门狗 150 秒** — 到点跳过本轮答题、关闭残留弹窗、视频继续播放

超时中止只作用于当前这一轮答题，不会中断整个刷课任务。

### 视频播放不再检测随堂题

视频播放中途弹出随堂题时不做任何介入，等卡顿检测判定卡住并提示。独立测验页面仍保留自动答题。

### 顺带修正

此前代码里的答题时长预算参数虽然传了值，但从未真正生效，属于摆设，现已接入实际计时。此外为项目内所有 HTTP 请求补齐了超时保护。
