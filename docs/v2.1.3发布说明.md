### 为什么做这一版

账号在平台被封，封禁原因是「**功能描述违规**」。

复盘结论：上一轮只把**宣传素材**（视频口播、标题、标签）过了合规机检，
**软件本体和分发链路整个漏掉**——安装包属性、桌面快捷方式、窗口标题、
任务管理器进程名、数据目录名、仓库描述、落地页标题，全都还是旧定位。
那些是任何审核一眼就能看到的证据，比视频标题严重得多。
**所以换平台不解决问题，只能改软件本身。**

### 已核对的行为

- **改名会影响数据目录**：Electron 的 userData 目录名直接来自 productName。
  改名的瞬间新版会指向一个全新空目录，老用户会看到「账号和进度全没了」。
  `src/shared/paths.ts` 负责迁移，三条原则已用 5 个回归用例锁住：
  只搬不删（旧目录原地保留）、目标已有数据就整个跳过、迁移失败不拦启动。
- **`fs.cpSync` 不能用于这条路径**：它在「目标是不存在的目录」时（正是
  进度目录的情形）会在 Windows 上直接终止进程，try/catch 接不住、退出码 127、
  无任何堆栈。已换成自建的 `copyPath()`。
- **合规机检新覆盖三层**：产品元数据（package.json / electron-builder.yml）、
  软件本体（窗口标题 / 数据目录名 / 设置页与关于页）、分发链路（落地页 /
  README / docs）。首跑即抓出 **11 处漏网**。
- **三处名称必须逐字相同**：`package.json.productName` /
  `electron-builder.yml.productName` / `paths.ts` 的 `APP_DIR_NAME`。
  不同步会出现「安装包叫新名、快捷方式叫旧名、数据目录又是第三个名」。
- **引擎内部的技术性描述未改**：URL 路由、DOM 选择器、「超星字体替换」这类
  注释保留原词——排查真机故障时要对得上页面。机检只锚定面向用户的字符串。
- **本版是合规定位的终点**：应用能力没有任何增删，功能与 v2.1.2 完全一致。

### 未验证的部分（如实记录，勿删）

## 二、功能与体验变更

### 1. 名称与界面改为中性表述

软件的应用名、窗口标题、桌面快捷方式、图标、关于页与设置页文案
统一改为「课程任务助手 CourseHelper」，任务页主按钮改为「开始运行」，
设置页与首页提示中的平台专属称谓改为通用表述。

功能本身没有任何变化——它始终只处理使用者自己的账号。

### 2. 接口地址自动纠正（v2.1.2 功能的延续）

在服务商文档里复制完整接口路径（以 `/chat/completions` 结尾）直接粘贴到
「接口地址」，保存时会自动去掉结尾并同步显示纠正后的值。老配置无需重存。
密钥无效时错误提示会明确指出「密钥无效或未授权」。

### 3. 修复：一个章节里的多个任务点，之前只做得到第一个

平台改了课程页的结构，现在一个章节里的多个任务点是**分标签页**呈现的
（章节顶部写着「1课程视频 2章节测验」），同一时刻只加载当前那一个。

此前程序只读到第一个任务点就认为「本章没有活可干了」，于是一个章节里
后面的测验/文档从来没被处理过——用户看到的就是「视频没放完就去答题」。

现在会**逐个标签页遍历**：当前任务点完成后自动切到下一个，直到本章全部
任务点处理完。

同时修掉了两个连带问题：

- **课程页已改版**：进入课程的方式变了，程序此前打不开章节列表，
  日志会报「未找到章节」。现在会自动点「进入课程」再读目录。
- **未配置 AI 通道时不再报错退出**：此前在开跑自检阶段读取空的通道配置
  会抛异常，用户只看到一句「出错」。现在会正常提示「未配置（缺 API Key 和
  接口地址）」并继续跑其它任务。

### 4. 新增：任务点分页的诊断日志

章节有多个任务点时，日志会列出全部标签（形如 `本章共 2 个任务点
（1课程视频 / 2章节测验），逐个处理`），切换到第几个也会明确记录，
反馈问题时不用再靠猜。

### 5. 新增：混合章节的诊断日志

判定为测验但页面里仍有未播完的视频时，日志会打出任务点清单，
一眼能看出是「类型判错」还是「选错了任务点」。

## 三、升级说明

- **旧用户：账号与学习进度会自动迁移，无需重新登录。**
  迁移只复制、不删除原目录；若你曾在旧目录下手动改过配置，以旧目录为准。
- **数据目录名变了**：由旧名称改为 `课程任务助手 CourseHelper`（位于
  `%APPDATA%`）。旧目录会保留在原处，确认新版本一切正常后可自行删除。
- Windows SmartScreen 提示「已保护你的电脑」仍是未购买代码签名证书的
  正常现象，点「更多信息 → 仍要运行」。
- 使用须知不变：本工具仅供学习与技术研究，请遵守所在学校与平台的使用规则。
