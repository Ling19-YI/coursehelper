## 二、发布说明正文（复制以下全部内容）

## 更新内容

### 修复：AI 答题配好了却一直「无解」（本版最重要）

「为什么本地能跑、用户不行」的根因找到了，是几层问题叠在一起：

**一、失败不上浮。** 调用 AI 出错时原因只写进了主进程终端，软件里看到的永远是
「无解，留空」。密钥过期、模型名写错、接口地址填错——表现完全一样，全都被误当成
「模型答不出来」。现在失败会把原因一起亮在日志里；如果是**推理把输出预算吃光了**，
会自动加倍预算重试一次。

**二、输出预算一开始就给足。** 推理模型会先把输出额度花在「思考」上，正文只能用剩下的。
此前先给一个小的、失败再翻倍，等于烧两遍额度还是拿不到答案。现在第一发就给足。

**三、配置判定两边不一致。** 接口地址是必填项，但设置页只检查了密钥：只填密钥不填
地址时，设置页显示「已配置」、开关打得开，引擎那头却算出「未配置 AI 接口」。现在两边
判定一致，地址留空会当场拦下。

**四、启动自检会说清缺什么。** 原来只说「未配置」，现在直接列出是缺 API Key 还是缺接口地址。

### 调整：AI 只保留一条通道

删掉了「旧版 DeepSeek 单密钥」这条回退路径。它没有界面能维护，密钥过期后完全静默失效，
而设置里根本没有地方能改——是前面那些「配好了却无解」的另一个来源。多模态模型本身
就能读文本，不需要再养第二条密钥。

### 修复：一个章节里同时有视频、文档和测验时，只做测验

超星把同一章的不同类型任务点**并列**放在同一个页面里（视频、文档、测验的框架同时存在，
只是显示其中一个）。旧逻辑只问「页面上有没有测验」，有就整章按测验做——所以「视频 + 测验」
的章节里，视频永远不播。

现在按「当前该做的那一个任务点」分派，一页里的视频、文档、测验会依次做完。

### 修复：一个章节里的第二个任务点被漏掉

实测发现两处：

- 第一个视频播完后，它身上的「当前目标」标记没被清掉，导致下一轮又选中它，
  第二个视频永远不播，整章就停在那里。
- 判「看完了」比平台记账早几秒，中间读到的是旧数字，程序误以为「这一轮白做了」
  而放弃整章。现在会等平台确认后再判断。

### 修复：手机扫码/人脸弹窗一出现就自己「继续」，二维码永远扫不上

如果你遇到过「弹出扫码或人脸采集，二维码却一直在刷新、根本来不及扫」——这版修好了。
根源是两个机制问题叠在一起，都不是「识别不准」：

- 程序嘴上说「已暂停自动操作」，但它在**页面里**还留着一个每 0.3 秒动一下的保活动作
  （本来是防止视频被平台判为挂机的）。而平台正是按「页面有没有变化」决定要不要重刷
  二维码的——于是二维码被程序**自己**一遍遍刷掉。现在人工介入期间，页面内的动作会
  和主程序一起彻底停住。
- 判「弹窗没了 = 你处理完了」。可二维码每次重绘都会让弹窗短暂消失，程序立刻以为你
  扫完了就恢复动作，动作又让二维码重刷，来回振荡。现在要求「连续几秒都查不到弹窗」
  才算真的处理完；等待超时也不会再自动恢复动作。

### 修复：被平台风控拦截时，会假装「任务完成」

承接上一条。被平台风控页（提示页面 / 安全验证）接管后，页面里读不到课程目录，之前
会把**剩下的课程全部标成「跳过」**，最后照样报一句「🎉 任务完成」——
**看起来刷完了，其实一个都没做**。现在会明确停下，并说明「本轮被平台风控中断（不是
任务完成）」，同时告诉你要去哪里手动完成验证。

### 新功能：中途手动切换章节，就从你点的那一节接着刷

以前你在浏览器里点了别的章节，程序会照自己的顺序继续，甚至把你拽回去，还可能把
完成记录记到错误的章节上。现在它会发现你切了章节，从你点的那一节重新开始；
被切走的那一章**不记账**（免得下次续刷时被误跳过）。

### 修复：随堂弹题的三个毛病

- 「每个视频只处理一次」的限制从未生效（计数写在了循环里，每轮都被重置）
- 弹题走了一条会回退到纯文本模型的答题通道
- 卡住时的提示没说清开关在哪，现在会指出设置里的位置

### 修复：在线更新对部分用户不可用

更新时会自动加一个缓存破坏参数，而备用下载源（GitCode）**只要 URL 带任何查询串就
返回 404**，所以这条回退路径从来没有成功过。报错文案看起来像「文件没传上去」，
方向被带偏了很久。现在两个下载源都能正常检查更新。

### 其他

- 上一版把 DeepSeek 专栏从设置里删了，但旧版残留的密钥仍会被读取；现在启动时清掉这些残留字段
- 识别不出的题目继续留空跳过，不会乱猜

## 升级方式

**已安装 v2.1.0**：打开软件 →「关于」→ 检查更新。

若提示「已是最新」但没有新版本，说明你走的是备用下载源，请直接下载安装包覆盖安装
（更新器的备用源有一条已知缺陷，本版已修复；装上这一版之后两个源都正常）。

**已安装 v2.0.0 或更早**：请直接下载安装包覆盖安装。
