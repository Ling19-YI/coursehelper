# 刷课助手 · 视频拍摄指南

面向后续所有要出视频的同学。每条视频动手前先看这份，能少返工很多次。

---

## 一、动手前必须知道的三件事

### 1. 录制环境比画质重要

现有素材是 Mac 录的 1722×1082 / 60fps，**清晰度完全够**。问题全出在别处：

| 问题 | 后果 |
|---|---|
| 窗口没最大化 | 左右大片空白，观众不知道该看哪 |
| 浏览器标签页外露 | 暴露其他网站、书签、个人账号 |
| 账号明文入镜 | **真实学号、学校、学院被拍进去** |
| 没有音轨 | 教程等于没教程 |
| 时长 6 分钟 | 用户划走 |

这些后期很难救，尤其打码后还要重新对口型。

### 2. 本项目有几个绝对不能露的东西

| 内容 | 风险 |
|---|---|
| 超星账号（手机号） | 真实身份，能定位到人 |
| 学校 + 学院 + 真实课程进度日期 | 组合起来能锁定具体学生 |
| Windows 用户名与本地路径 | 日志面板会打印 `C:\Users\xxx\...` |
| API Key | 即使设了开关也要遮 |

**特别注意**：日志面板会自动打印完整本地路径。如果视频里开着日志页，会暴露 Windows 用户名。这个很容易漏。

### 3. 国内用户主要在 GitCode

口播或字幕里给下载渠道时，**GitCode 放前面**：

```
GitCode（国内推荐）
https://gitcode.com/2603_95808828/coursehelp/-/releases

GitHub（备用）
https://github.com/Ling19-YI/coursehelper/releases
```

软件内置的在线更新已做双源回退：GitHub 拉不到会自动切 GitCode，用户不用管。

## 二、录制前的准备清单

### 软件环境

- [ ] 应用窗口**最大化到全屏**（不要拖到一边）
- [ ] 关闭所有无关窗口
- [ ] 浏览器用**无痕/隐私窗口**，避免书签栏和个人账号入镜
- [ ] 只开需要的那一个标签页
- [ ] macOS 可用 `Cmd+Shift+5` 录全屏；Windows 可用浏览器全屏 `F11`

### 应用状态

- [ ] 设置页里倍速设成要演示的值（默认 1x，演示加速建议 2x）
- [ ] AI 自动答题开关：**演示视频建议关闭**
      开着会卡在题目环节，题型不适配概率很高
- [ ] 清空课程进度，进度条从 0 开始更直观
      数据目录：`%APPDATA%\刷课助手 CourseHelper\data`

### 隐私

- [ ] 确认账号输入框是掩码显示（软件本身是，点上去是圆点）
- [ ] 如果需要演示登录，**先想好怎么遮账号**
- [ ] 关掉「日志」标签页，或至少确保不长时间停留

### 录制参数

| 平台 | 工具 |
|---|---|
| macOS | `Cmd + Shift + 5` → 选「录制屏幕」→ 点**选项** |
| Windows | `Win + G`（Xbox 游戏栏）或 OBS |

必调选项：

- [ ] 录制区域：**整个屏幕**（不要只录窗口，容易截不全）
- [ ] 麦克风：选对设备，**录一段试音回放确认**
- [ ] 鼠标点击高亮：**打开**（教程里观众要看到点了哪）
- [ ] 倒计时：5 秒（给你时间切窗口）
- [ ] 保存位置：桌面

**录完先回放检查两件事**：有没有声音？有没有露不该露的？

## 三、分镜脚本

按段落录，**不要一次录到底**。中途出问题只需重录那一段。

### 第一段 · 开场（8 秒）

**画面**：软件主界面，全屏
**字幕**：`v1.5.1 · 应用内更新`

```
刷课助手更新到一点五一点版本了，
这次把更新功能做了进去。
以后有新版本，在软件里点一下就能更新，
不用再重新找安装包。
```

### 第二段 · 下载（20 秒）

**画面**：浏览器打开 GitCode 发行版页 → 鼠标圈出安装包文件名
**字幕**：`认准文件名 CourseHelper-Setup-*.exe`

```
下载有两个地方，都能用，国内建议用第一个。
第一个是 GitCode，国内访问很快，不需要梯子。
第二个是 GitHub，如果第一个打不开，换这个。
找到最新版本，点那个一百一十兆的安装包下载。
注意别下错，源码那几个压缩包是没用的。
```

### 第三段 · 安装（12 秒）

**画面**：安装向导录屏
**字幕**：`系统提示点「继续运行」`

```
下载完双击打开。
第一次打开可能会有系统的安全提示，点继续运行就行。
安装位置可以用默认的，也可以自己改。
装完桌面上会有图标，打开就能用。
```

### 第四段 · 登录（12 秒）

**画面**：设置页，**账号要遮**
**字幕**：`🔒 账号仅存本机，系统加密`

```
第一次用要点登录，填你的学习通账号和密码。
账号密码只存在你自己电脑上，系统加密存着，
不会上传到任何服务器。
登录成功之后，软件会自动把你学过的课列出来。
```

### 第五段 · 使用（30 秒）

**画面**：勾选课程 → 点开始 → 观察倍速生效
**字幕**：`1x / 1.25x / 1.5x / 2x`

```
在课程列表里勾选要刷的课，然后点开始。
视频任务点会自动播放，可以调倍速，二倍速能省不少时间。
文档类的任务点会自动往下滚，滚到底就算完成。
随时可以暂停或者停止，进度会记住，下次接着刷。
```

### 第六段 · 结尾（12 秒）

**画面**：关于页 → 软件更新卡片
**字幕**：`GitHub 不可达时自动切 GitCode`

```
以后有新版本，打开软件的关于页面，点检查更新就行。
国内网络打不开 GitHub 也没关系，软件会自动换到 GitCode 下载。
完全免费，没有激活码，也不用注册。
有问题或者遇到特殊情况，欢迎在评论区留言，我会一条条看。
```

## 四、口播音频

用 [manbo-tts](https://github.com/xmimu/manbo-tts/releases)（曼波语音生成器）。

| 项 | 说明 |
|---|---|
| 下载 | `manbo-tts_0.1.5_x64-setup.exe`（Windows） |
| 免费额度 | 每 IP 每天 **50 次**，24 句一次能做完 |
| 语速 | 教程建议 **-10**，偏慢更清楚 |
| 命名 | `01.mp3`、`02.mp3`……按分镜顺序 |

注意事项：

- 链接**不要念出来**，放字幕。念网址听感极差，且平台会判定导流
- 每句生成后**回放试听**，别等全部生成完再听
- 句 5、6 提到渠道时语气可以稍作停顿，给画面时间

## 五、后期剪辑

### 输出参数

```
分辨率   1920×1080（横版）或 1080×1920（竖版）
帧率     30fps
编码     H.264 + AAC
码率     8 Mbps
音频     归一化到 -16 LUFS
```

平台（抖音/B站）都会自己做归一化，自己先对齐可以避免听着忽大忽小。

### 用 ffmpeg 拼接音频

```bash
# 按编号顺序拼接 24 段 mp3
ffmpeg -f concat -safe 0 -i list.txt -c:a aac -b:a 192k voice.m4a

# list.txt 格式（每行一个文件）
file '01.mp3'
file '02.mp3'
```

### 合成画面 + 旁白

```bash
ffmpeg -i video.mp4 -i voice.m4a \
  -c:v copy -c:a aac -b:a 192k \
  -shortest output.mp4
```

### 打码（确实需要时）

```bash
# 遮挡指定区域：x:y:宽:高
ffmpeg -i in.mp4 -vf "drawbox=x=180:y=210:w=120:h=24:color=black@1:t=fill" out.mp4
```

坐标用图片编辑器量，或者先截一帧用画图工具量。

**优先打码而不是重录**——但如果账号出现在很多不同时刻，重录更干净。

## 七、本项目特有提示

### 版本号别写错

发布页的标题和 tag 必须一致。当前最新是 v1.5.1。

### 双渠道发布

每次发版要同时发到：

- `https://github.com/Ling19-YI/coursehelper/releases`
- `https://gitcode.com/2603_95808828/coursehelp/-/releases`

三个文件缺一不可：

| 文件 | 作用 | 缺了会怎样 |
|---|---|---|
| `CourseHelper-Setup-版本号.exe` | 安装包本体 | 用户装不了 |
| `latest.yml` | 更新清单 | **在线更新直接失效** |
| `.exe.blockmap` | 差分下载 | 更新变慢 |

`latest.yml` 很小（几百字节），最容易在上传时漏掉，但它是自动更新的命脉。

### 用户常问的问题（可做成 FAQ 视频）

- **答题卡住怎么办** → v1.5.0 起有超时兜底，会跳过并继续播放，不会再卡死
- **换了账号还是登旧号** → v1.5.1 已修
- **支持雨课堂吗** → 正在开发中，尚未上线
- **收费吗** → 完全免费，无激活码

## 八、常见坑

| 坑 | 后果 | 怎么避 |
|---|---|---|
| 窗口没最大化 | 大量空白 | 录制前最大化 |
| 忘了关日志页 | 暴露本机路径 | 录制前切到别的标签页 |
| 只下源码包 | 观众以为不能用 | 视频里明确提醒 |
| 没有音轨 | 教程失效 | 录完必须回放听 |
| 打完码没回看 | 遮错位置或漏遮 | 导出前完整看一遍 |
| 学号 + 学校同时露出 | 可定位到人 | 两个都要处理 |
| 6 分钟太长 | 完播率低 | 控制在 90 秒内 |
