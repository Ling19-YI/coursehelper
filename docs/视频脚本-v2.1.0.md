## 为什么要重写

v1.5.1 时期的主卖点是"应用内更新""倍速"。这两个功能现在早就是标配了，
再讲没有区分度，而且观众点进去发现没有 AI 答题，转化会打折。

v2.1.0 真正能打的三个点：

| 卖点 | 强度 | 为什么 |
|---|---|---|
| **遇到人脸识别会停下等你** | 最强 | 所有人都在吹"全自动"，你讲"它会停下来"，反而是可信度 |
| **看图答题 + 题库沉淀** | 强 | AI 能力首次进入功能列表，是这版的记忆点 |
| **一章多任务点真跑完** | 中 | 最硬的 bug 修复，用户能感知但不一定能确认 |

**核心叙事转向：从"我做了个刷课工具"改成"我做的工具，边界很清楚"。**

分六段，**分段录不要一次到底**，中途出问题只补那段。

### 第一段 · 开场（12s）

**画面**：主界面全屏，日志页滚动的真实画面

```
三十多门课要人肉点完，我给自己写了个桌面工具。
这是一个Windows 小程序，两千多次下载，完全免费。
```

> 字幕：`v2.1.0 · 最新版`

### 第二段 · 界面（15s）

**画面**：全屏展示单窗口布局，鼠标划过左右分栏

```
一个窗口里，左边是控制台，右边就是学习通的真实页面。
不是模拟点击，是真的把页面嵌进来，你随时看得见它在干什么。
```

### 第三段 · 功能（25s）

**画面**：勾选课程 → 点开始 → 视频进度推进 → 切到文档任务点

```
视频任务点自动续播，倍速可以调，两倍速能省不少时间。
文档任务点会自动往下滚，滚完还会再用平台的完成标记校验一次，
不会出现白刷一遍进度没涨的情况。
```

### 第四段 · AI 答题（15s）

**画面**：章节测验界面，作答动画

```
章节测验和随堂弹题都能答，需要看图的题也能处理。
答过的题会存进本地题库，同样的题下次直接命中，不再重复调接口。
```

### 第五段 · 边界（12s）

**画面**：人脸识别弹窗出现 → 日志停住 → 处理完后自动继续

```
有一点要专门说：检测到人脸识别、扫码、验证码，它会停下来等你，
不会硬闯，也不会一边刷一边把你的二维码刷掉。
这是我特意做的，等你处理完会自动接着跑。

> 这段是信任锚点，**不要剪掉**。它是这版最强的差异点。

### 第六段 · 结尾（10s）

**画面**：关于页

```
完全免费，没有激活码，也不用注册。
账号密码系统加密存你自己电脑上，不上传任何服务器。
有问题评论区留言，我会一条条看。

## 用现成流水线重出片

`promo/` 目录已经有 HTML 渲染 + TTS + ffmpeg 合成的完整流程，
脚本沿用 `narration.json` 格式：

```json
[
  { "t0": 0.3,  "text": "三十多门课手动点，我写了个 Windows 小工具。" },
  { "t0": 3.4,  "text": "一个窗口，左边控制，右边就是学习通真实页面，随时看得见。" },
  { "t0": 8.0,  "text": "视频任务点自动续播，文档自动滚到底。" },
  { "t0": 13.2, "text": "章节测验能看图答题，答过的存进本地题库，下次直接命中。" },
  { "t0": 18.4, "text": "检测到人脸识别，它会停下来等你处理完再继续。" },
  { "t0": 23.6, "text": "完全免费，没有激活码，账号只存在你自己电脑上。" },
  { "t0": 27.4, "text": "详情看主页。" }
]
```

### 出片命令

```bash
cd promo

# 1) 改src/narration.json 为上面的内容

# 2) TTS 配音（manbo-tts，免费额度 50 次/天/IP，24 句够用）
node scripts/build-voice.mjs          # 横版
node scripts/build-vertical-voice.mjs # 竖版

# 3) 渲染 + 合成
node scripts/build-promo.mjs          # 横版 → out/coursehelper-promo-30s-vo.mp4
node scripts/build-vertical.mjs# 竖版 → vertical/out/coursehelper-vertical-30s-vo.mp4
```

### 输出参数（沿用现有规范）

```
竖版   1080×1920   30fps   H.264 + AAC   8Mbps   -16 LUFS
横版   1920×1080   30fps   H.264 + AAC   8Mbps   -16 LUFS
```

TTS 语速建议 `-10`，偏慢更清楚。**链接不要念出来**，放字幕。

## 隐私红线（重拍前再确认一遍）

| 绝对不能出现 | 原因 |
|---|---|
| 超星账号 / 手机号 | 能定位到人 |
| 学校 + 学院 + 课程进度日期 | 组合起来能锁定学生 |
| Windows 用户名与本地路径 | 日志面板会自动打印 `C:\Users\xxx\...` |
| API Key | 即使设了开关也要遮 |
| 浏览器书签栏 / 其他标签页 | 录屏前开无痕窗口 |

**特别注意**：日志页会自动打印完整本地路径。第五段要展示日志，记得先切到别的标签页。
